# 4DN Firing Timing Probe Schematics

This directory contains the schematics for the 4DN Firing Timing Probe.
See [releases][]: schematic.pdf for a PDF version.

The probe is simple enough that it'll work with a breadboard or protoboard. If
you want a proper PCB, use KiCad (10+) and send the gerbers to a fab house.

A gerber file for jlcpcb can be found in [releases][]: 4dn-firing-timing-probe-gerbers.zip.

[releases]: https://github.com/doge-gif/4dn-firing-timing-probe/releases/latest
